# Roxana Arnet portfolio

A static site with no build step. Open `index.html` in a browser to preview it.

## Add photos

1. Put image files in the matching folder under `images/` (for example `images/helix/01.jpg`).
2. Open the page in `pages/` (for example `pages/helix.html`).
3. Replace a dashed tile with
   `<figure><img src="../images/helix/01.jpg" alt="Describe the photo"><figcaption>Caption</figcaption></figure>`.

For your portrait, save it as `images/portrait.jpg` and replace the dashed circle in `index.html` with
`<div class="portrait"><img src="images/portrait.jpg" alt="Roxana Arnet"></div>`.

Resize photos to about 1600 px on the long edge before uploading so pages load quickly.
